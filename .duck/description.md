# The same hack as the original project
The same renderer as the original 1-week project, with some bug fixes along the way, hopefully there's no `jsx2html2shell` (fancy heard of [`react2shell`](https://react2shell.com/) everyone?) :)

Everything is statically rendered on build time, which mean, almost instant loading time with no javascript. Non-nerd speaks: it just means that your browser won't have a hard time showing this. **(IE is not supported)**.
