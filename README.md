# Well
A fancy project list so you can see what project I am doing, both of my public and private projects.

This is a improved version of my coursera project - which you can locate the original project here: [`04-duck-project-index`](https://github.com/lilunderDuck/glorified-abandonware/tree/main/docs/04-duck-project-index). I really like the idea I came up, so I made this :)

# How it works
If you really don't want to read my horrible code, all it does is:
- Read a bunch of folder from `D:/projects`, I organize every projects in that path.
- Check if it contains a `.duck` folder and `metadata.json`. If so, gather it.
- Render the data it gathered.
