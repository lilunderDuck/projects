BigChadGuys+ decompilation

Decompilation of a minecraft modpack called: BigChadGuys+ (Non Cobblemon!) by jflec (with some additional mods) for fabric 1.20.1

Basically

A destructive decomp

This is an attempt to optimize my modified BCG+ NC modpack for my forever world and the launch time, while also adding some unfixable mods that just crash when opening the world (Create Big Cannons for example).

Every mods are going to be decompiled to identify any memory leaks, or optimize any resource intensive part of the code.

What I will do (nerd details alert)

  • Trying to port some mods to Fabric 1.20.1, because... why?
  • Mark all Java classes as final, don't ask me why on that.
  • Remove log calls on production.
  • Compile the code to newer Java version, we might be getting the benefit of AOT (hopefully) in the future, or Project Valhalla, or both (Valhalla when?)
